English

What is Mio?

Mio is a free, MIT-licensed native desktop coding agent for the MiMo model family, for macOS and Windows. Since 0.4.0 it is the official DeepSeek Harness Desktop — upstream's workspace, tools and settings — with Mio's identity and MiMo defaults layered on top.

Who is Mio for?

Mio is for developers who want to use MiMo models in a desktop workspace to work on their own code projects.

What problems does Mio help solve?

Mio helps you understand an existing codebase, implement features and investigate and fix bugs through natural-language requests. Review generated changes before using them.

Why is it built on DeepSeek Harness?

The hard parts of a desktop agent — the tool loop, session persistence, model routing, the workspace UI — already exist in dsh, and they are open source. Mio composes them instead of forking them: a pinned upstream source, a reviewed overlay, and MiMo configured through dsh's own provider. Upstream improvements arrive by moving a version pin.

Is Mio a DeepSeek product?

No. DeepSeek Harness is DeepSeek's open-source agent harness (MIT). Mio is an independent project built on it and is not a DeepSeek product.

Which MiMo models does it support?

MiMo V2.6 Flash, the default for new sessions, and MiMo V2.6 Pro. Thinking switches on or off per session; Off and High map to MiMo's thinking switch, with no graded effort levels. UltraSpeed is an opt-in build flag for accounts that support it.

Can I talk to Mio, and can it read replies aloud?

Yes, since 0.4.1. The mic in the composer transcribes your request with MiMo ASR into an editable draft, and the speaker button under each reply reads it with MiMo TTS in one of nine voices. Both use your MiMo account; recordings and reply text are sent to the MiMo API.

Which platforms does Mio run on?

macOS on Apple Silicon and Intel, Developer ID signed and notarized, and Windows x64, unsigned. Linux will follow separately. There is no terminal (TUI) version planned.

Will my sessions and settings carry over?

From 0.4.x, the data directory is retained. Exit GUI and CLI and back it up before upgrading; automation is now built in, and explicitly disabled settings stay disabled. Old normal transcript display becomes detailed. To roll back, restore the old installer and the complete pre-upgrade backup. Data from 0.3.x is not imported.

Is Mio an official Xiaomi product?

No. Mio is an independent, community-maintained project. It is not affiliated with, sponsored by, or endorsed by Xiaomi Inc., and it connects to the MiMo model platform purely as a third-party client.

How much does it cost, and how do I get started?

The app is free and MIT-licensed; you pay only for MiMo API usage. Download the installer, then paste a MiMo API key from platform.xiaomimimo.com on the welcome screen: sk- keys are pay-as-you-go, tp- keys are token plans and ask for a region. You can skip that step and add the key later from the Models page.

简体中文

什么是 Mio？

Mio 是面向 MiMo 模型家族的免费开源（MIT）原生桌面代码智能体，支持 macOS 与 Windows。自 0.4.0 起，它就是官方 DeepSeek Harness Desktop——沿用上游的工作区、工具与设置——再叠加 Mio 的品牌与 MiMo 默认配置。

Mio 适合谁？

Mio 适合希望在桌面工作区中使用 MiMo 模型处理自己代码项目的开发者。

Mio 能解决什么问题？

Mio 帮助你通过自然语言理解现有代码、实现功能、定位和修复问题。使用生成的改动前，请先审阅。

为什么建立在 DeepSeek Harness 之上？

桌面智能体最难的那几块——工具循环、会话持久化、模型路由、工作区界面——dsh 都已做好，而且是开源的。Mio 选择组合而不是 fork：锁定版本的上游源码、一层审阅过的补丁，以及通过 dsh 自带 provider 完成的 MiMo 配置。上游的改进，挪一下版本锁就继承过来。

Mio 是 DeepSeek 的产品吗？

不是。DeepSeek Harness 是 DeepSeek 开源的智能体运行时（MIT），Mio 是基于它构建的独立项目，并非 DeepSeek 的产品。

支持哪些 MiMo 模型？

MiMo V2.6 Flash（新会话默认）与 MiMo V2.6 Pro。推理可按会话开关；Off 与 High 对应 MiMo 的 thinking 开关，没有分级强度。UltraSpeed 是面向支持该模型账号的可选构建开关。

可以用语音和 Mio 交流吗？

可以，自 0.4.1 起。输入框里的麦克风会用 MiMo ASR 把你的话转成可编辑的草稿；每条回复下的朗读按钮会用 MiMo TTS 以 9 种音色之一读出来。两者都使用你的 MiMo 账号，录音与回复文本会发送到 MiMo API。

Mio 能在哪些平台运行？

macOS（Apple Silicon 与 Intel，已 Developer ID 签名并公证）与 Windows x64（未签名）。Linux 后续单独提供。不计划提供终端界面（TUI）。

升级后会话和设置会保留吗？

从 0.4.x 升级会保留数据目录。升级前退出 GUI 与 CLI 并备份；自动化已内建。旧 normal 会话展示变为 detailed。回退时恢复旧安装包与完整升级前备份。0.3.x 数据不导入。

Mio 是小米官方产品吗？

不是。Mio 是一个独立的、由社区维护的项目，与小米公司（Xiaomi Inc.）无附属、赞助或背书关系，仅作为第三方客户端连接 MiMo 模型平台。

费用如何？如何开始使用？

应用本身免费、采用 MIT 许可，你只为 MiMo 的 API 用量付费。下载安装包后，在欢迎页粘贴来自 platform.xiaomimimo.com 的 API Key：sk- 为按量付费，tp- 为订阅套餐并需选择地域。这一步也可以跳过，之后在模型页里补填。
