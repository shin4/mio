# Mio 0.5.0

Mio 升级到官方 dsh Desktop **0.2.0-rc.2**。Mio 使用独立的稳定版本号，内置内核仍为 RC。

- **1M 上下文**：MiMo V2.6 Flash 与 Pro 默认使用 1,048,576 tokens，输出预算仍为 32,768 tokens。旧配置继承的 256K 默认值自动修复，显式自定义上限保留。
- **`mio` 命令**：在应用的命令设置中安装后，可从终端使用内置运行时。GUI 与 CLI 共用默认数据目录；显式 `MIO_HOME` 展开 `~`，相对路径以用户主目录为基准，空值拒绝。开发入口采用相同解析规则。
- **启动修复更可靠**：等待原生设置事务队列就绪后，再修复保存的图片能力、上下文和隐藏的默认 preset，覆盖 Windows 启动场景。
- 保留图片、语音输入、朗读与音视频工具。产品 analytics 默认关闭；上游 Session Log 是独立设置。
- 旧 `transcriptView: normal` 按上游规则变为 `detailed`；新 profile 默认 `standard`。

## 升级前后

升级前退出 **GUI 和 CLI**，备份完整 userData 及自定义 home。已有 0.4.x 数据目录继续使用；不导入 0.3.x 数据。

**已有自动化任务必须重新启用**：打开“插件 → 官方 → 自动化任务”，启用
`@deepseek-ai/dsh-experimental-schedule-bundle`。任务保留在磁盘，重新启用前不会投递；
保留自定义 Schedule 配置，启用后确认任务列表和下次触发时间。

回退时先保留新版数据副本，再恢复旧安装包与完整升级前备份；不要让旧运行时直接读取新版写入后的数据。
第三方插件与历史模型的兼容性取决于各自实现，不承诺所有配置自动兼容。

## 下载与验证

- macOS arm64 / x64：Developer ID 签名、公证、staple 和 Gatekeeper 验证。
- Windows x64：**未签名**安装包，文件名带 `-unsigned`；安装时可能出现 SmartScreen / 未知发布者提示。自动更新校验 SHA-512。
- 使用 `SHA256SUMS.txt` 核对下载；`mio-0.5.0-qualification.json` 提供三平台的源码、上游 SHA、安装包哈希与签名证据。

本次真实 API 验证限定于已测试的 **CN Token Plan** 账户与 Flash / Pro；PAYG、SGP / AMS 及 UltraSpeed 的真实账户覆盖不在本次声明中。
自动化覆盖旧会话续接、完整备份回退和 Schedule 数据保留；跨平台人工 UI 全矩阵与生产更新回退演练不作为已完成事项声明。
