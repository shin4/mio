## Mio v0.4.0

Mio Desktop now uses the official DeepSeek Harness Desktop, with Mio branding and MiMo model configuration.

### Changes

- Official dsh Desktop 0.1.7-rc.2 foundation, preserving its native workspace, settings and tools.
- MiMo V2.6 Flash by default, with V2.6 Pro available. Thinking can be enabled or disabled.
- Native MiMo API-key setup, Token Plan region selection, and Chinese/English experience.
- Mio identity, icons and theme. UltraSpeed remains disabled in this release.

### Downloads and signing

- **macOS Apple Silicon:** use the `mac-arm64.dmg` installer or ZIP.
- **macOS Intel:** use the `mac-x64.dmg` installer or ZIP.
- **Windows x64:** use the `win-x64-unsigned.exe` installer. **This Windows release is unsigned** and Windows may show an unknown-publisher/SmartScreen prompt. macOS downloads are Developer ID signed and notarized.
- SHA-256 checksums and per-platform qualification evidence accompany the downloads.

### Upgrade notes

- Install manually; automatic updates are not enabled in this release.
- This Desktop starts with a fresh data directory. Previous sessions, workspaces, settings and API keys are not migrated; reconnect your MiMo account in the welcome screen.
- Linux is not included in v0.4.0 and will follow separately.
