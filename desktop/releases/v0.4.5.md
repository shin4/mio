## Mio v0.4.5

修复 0.4.4 的图片输入：此前连接过 MiMo 的用户，MiMo V2.6 现在也能收图片了。

### 修复

- **V2.6 图片输入对老配置生效** — 0.4.4 为 MiMo V2.6 Flash 和 Pro 声明了图片输入，但首次连接 MiMo 时（欢迎页保存接入地址，或在模型页保存过设置）Mio 会把当时的整张模型列表存进你的配置，而那份列表早于图片支持，会覆盖新声明，输入框因此继续拒绝图片。Mio 现在每次启动时为这些已保存的模型补上图片支持；你手动设置过输入类型的模型保持不变。无需任何操作，更新后重启即可。

### 下载与签名

- **macOS Apple Silicon：** `mac-arm64.dmg` 或 ZIP。
- **macOS Intel：** `mac-x64.dmg` 或 ZIP。
- **Windows x64：** `win-x64-unsigned.exe`。**Windows 安装包未签名**，可能出现未知发布者 / SmartScreen 提示；自动更新以 SHA-512 校验下载内容。macOS 安装包已 Developer ID 签名并公证。
- 附 SHA-256 校验和、各平台验证记录，以及自动更新使用的 `nightly-mac.yml` / `nightly.yml`。

### 升级说明

- **从 0.4.2 至 0.4.4 升级**：通过自动更新送达，下载前和重启安装前都会询问；也可在应用菜单中点**检查更新…**。
- **从 0.4.0 或 0.4.1 升级**：这些版本没有更新功能，请手动覆盖安装一次。会话、设置和 MiMo Key 都会保留。
- 内核仍为官方 dsh Desktop 0.1.7-rc.2。

---

Fixes 0.4.4's image input: MiMo V2.6 now accepts images for people who connected MiMo before.

### Fixed

- **V2.6 image input on existing profiles** — 0.4.4 declared image input for MiMo V2.6 Flash and Pro, but when you first connected MiMo (the welcome screen saving your endpoint, or any save on the Models page) Mio stored the whole model list of the time in your profile. That list predates image support and overrode the new declaration, so the composer kept refusing images. Mio now fills in image support on those saved models at every startup; models you edited to state their own input types are left alone. Nothing to do: update and restart.

### Downloads and signing

- **macOS Apple Silicon:** `mac-arm64.dmg` or ZIP.
- **macOS Intel:** `mac-x64.dmg` or ZIP.
- **Windows x64:** `win-x64-unsigned.exe`. **This Windows installer is unsigned**; expect an unknown-publisher / SmartScreen prompt. Automatic updates verify downloads by SHA-512. macOS downloads are Developer ID signed and notarized.
- SHA-256 checksums, per-platform qualification evidence, and the `nightly-mac.yml` / `nightly.yml` update feed accompany the downloads.

### Upgrade notes

- **From 0.4.2 through 0.4.4**: arrives through automatic updates; Mio asks before downloading and before restarting to install. **Check for Updates…** in the application menu checks right away.
- **From 0.4.0 or 0.4.1**: those versions cannot update themselves; install over them once by hand. Sessions, settings and your MiMo key are kept.
- Still built on the official dsh Desktop 0.1.7-rc.2.
