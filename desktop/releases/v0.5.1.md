# Mio 0.5.1

Mio 升级到官方 dsh Desktop **0.2.1-rc.2**。这是 0.5.0 的维护升级；Mio 使用独立的稳定版本号，内置 dsh 内核仍为 RC。

- **自动化已内建**：沿用上游 Schedule，已有任务和设置保留，无需重新启用旧可选 bundle；显式禁用的设置继续保持禁用。升级和重启回归分别验证配置、任务与禁用状态保留。
- **原生凭据规则**：Desktop 优先使用保存的 API Key；headless 终端运行使用启动环境，不读取 Desktop 的凭据存储。MiMo 语音与音视频工具遵循同一规则。
- **精简补丁**：删除上游已覆盖的端口与构建入口补丁，保留必要的 MiMo 产品配置和集成，不分叉模型适配器或运行时内部实现。
- 保留 MiMo V2.6 Flash / Pro 的 1M 上下文、图片、语音输入、朗读、音视频工具与 `mio` 终端命令。产品 analytics 默认关闭；上游 Session Log 是独立设置。

## 升级前后

升级前退出 **GUI 和 CLI**，备份完整 userData 及自定义 home。已有 0.4.x / 0.5.0 数据目录继续使用；不导入 0.3.x 数据。升级后检查自动化任务列表和下次触发时间；已有显式禁用设置不会自动开启。

回退时先保留新版数据副本，再恢复旧安装包与完整升级前备份；不要让旧运行时直接读取新版写入后的数据。第三方插件与历史模型的兼容性取决于各自实现。

## 下载与验证

- macOS arm64 / x64：Developer ID 签名、公证、staple 和 Gatekeeper 验证。
- Windows x64：**未签名**安装包，文件名带 `-unsigned`；安装时可能出现 SmartScreen / 未知发布者提示。自动更新校验 SHA-512。
- 使用 `SHA256SUMS.txt` 核对下载；`mio-0.5.1-qualification.json` 记录三平台资格验证、源码与上游 SHA、安装包哈希和签名证据。

本次真实 API 验证限定于已测试的 **CN Token Plan** 账户与 Flash / Pro；PAYG、SGP / AMS 及 UltraSpeed 的真实账户覆盖不在本次声明中。旧会话续接、完整备份回退及 Schedule 升级/重启保留已在本地旧版 baseline 上回归；CI 缺少旧版 baseline 时会明确跳过相关测试。跨平台人工 UI 全矩阵与生产更新回退演练不作为已完成事项声明。
