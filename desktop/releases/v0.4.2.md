## Mio v0.4.2

Mio 开始自动更新，并修复了 macOS 上语音输入拿不到麦克风的问题。

### 新功能

- **自动更新** — Mio 会定期检查 GitHub 上的最新正式版，也可在应用菜单中点**检查更新…**。发现新版本后先询问是否下载，下载并校验完成后再询问是否重启安装，不会自动打断正在进行的工作。
- **设置 → 通用设置 → 语音输入语言** — 在「朗读音色」下方直接选择自动识别或中文，不必再进入插件页。
- **设置 → 通用设置 → 麦克风权限** — 显示 Mio 是否已获得麦克风权限；未授权时可一键发起系统授权，并提示在系统设置中打开的位置。

### 修复

- **macOS 语音输入无法使用麦克风** — 0.4.1 的签名缺少麦克风权限声明，系统直接拒绝录音且不弹出授权提示，系统设置中也看不到 Mio。0.4.2 已补上声明，首次录音时会弹出系统授权。
- **检查更新报错** — 0.4.1 中「检查更新…」总是提示“检查更新失败”，现在会真正检查。

### 下载与签名

- **macOS Apple Silicon：** `mac-arm64.dmg` 或 ZIP。
- **macOS Intel：** `mac-x64.dmg` 或 ZIP。
- **Windows x64：** `win-x64-unsigned.exe`。**Windows 安装包未签名**，可能出现未知发布者 / SmartScreen 提示；自动更新以 SHA-512 校验下载内容。macOS 安装包已 Developer ID 签名并公证。
- 附 SHA-256 校验和、各平台验证记录，以及自动更新使用的 `nightly-mac.yml` / `nightly.yml`。

### 升级说明

- **从 0.4.1 或更早版本升级需手动安装这一次**：旧版本没有更新功能。之后的版本会通过自动更新送达。
- 覆盖安装即可，会话、设置和 MiMo Key 都会保留。
- 若之前在系统设置中拒绝过 Mio 的麦克风权限，请在**系统设置 → 隐私与安全性 → 麦克风**中打开 Mio。
- 内核仍为官方 dsh Desktop 0.1.7-rc.2。

---

Mio now updates itself, and voice input on macOS can reach the microphone again.

### New

- **Automatic updates** — Mio periodically checks GitHub for the latest release; you can also choose **Check for Updates…** in the application menu. It asks before downloading and again before restarting to install, so work in progress is never interrupted.
- **Settings → General → Voice input language** — pick Auto-detect or Chinese right below the read-aloud voice, without visiting the Plugins page.
- **Settings → General → Microphone access** — shows whether Mio may use the microphone; when it may not, one click asks the system and the row says where to turn it on in System Settings.

### Fixes

- **macOS voice input could not use the microphone** — 0.4.1 was signed without the microphone entitlement, so macOS silently refused recording, never prompted, and did not list Mio under Microphone. 0.4.2 carries it; the system asks on first recording.
- **Check for Updates failed** — in 0.4.1 it always reported a failure; it now really checks.

### Downloads and signing

- **macOS Apple Silicon:** `mac-arm64.dmg` or ZIP.
- **macOS Intel:** `mac-x64.dmg` or ZIP.
- **Windows x64:** `win-x64-unsigned.exe`. **This Windows installer is unsigned**; expect an unknown-publisher / SmartScreen prompt. Automatic updates verify downloads by SHA-512. macOS downloads are Developer ID signed and notarized.
- SHA-256 checksums, per-platform qualification evidence, and the `nightly-mac.yml` / `nightly.yml` update feed accompany the downloads.

### Upgrade notes

- **Install 0.4.2 manually once from 0.4.1 or earlier**: those versions cannot update themselves. Later versions arrive through automatic updates.
- Install over the existing app. Sessions, settings and your MiMo key are kept.
- If you previously denied Mio the microphone, turn it on in **System Settings → Privacy & Security → Microphone**.
- Still built on the official dsh Desktop 0.1.7-rc.2.
