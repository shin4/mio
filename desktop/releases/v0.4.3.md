## Mio v0.4.3

Mio 的界面更干净：去掉了 DeepSeek 账号登录、反馈入口和内测声明，首页换上 Mio 自己的双语标语，思考等级按 MiMo 的实际能力只保留开和关。

### 变化

- **首页新标语** — 空白会话页显示「于深处写下光」，下方是英文 *Write Light into the Deep*；旁边的角标改为「基于 DeepSeek Harness」，如实说明 Mio 构建在官方 dsh 之上。
- **不再出现 DeepSeek 账号登录** — 去掉设置中的账号页、侧边栏的账号菜单和按账号计费的模型线路。MiMo 与 DeepSeek 都只通过 API Key 接入，DeepSeek 的 API Key 线路照常可用。
- **去掉反馈入口** — 回复下的点赞 / 点踩、反馈弹窗和 `/feedback` 命令不再显示。
- **去掉内测声明与 DeepSeek 新手引导** — 用浏览器打开同一个本机服务时，也不会再弹出「内测声明」或「配置 DeepSeek 官方模型」的对话框。
- **Agent 预设更精简** — 新任务可选「标准模式」和「创造模式」（创建自定义预设的入口）；「PTC 模式」和「极简模式」不再出现在设置和模式选择器中。
- **思考等级只有开和关** — 按小米官方文档，MiMo V2.6 的思考只有开启与关闭两档。模型菜单里去掉了与「High」重复的「Default」，现在只剩 Off（关）和 High（开）。

### 下载与签名

- **macOS Apple Silicon：** `mac-arm64.dmg` 或 ZIP。
- **macOS Intel：** `mac-x64.dmg` 或 ZIP。
- **Windows x64：** `win-x64-unsigned.exe`。**Windows 安装包未签名**，可能出现未知发布者 / SmartScreen 提示；自动更新以 SHA-512 校验下载内容。macOS 安装包已 Developer ID 签名并公证。
- 附 SHA-256 校验和、各平台验证记录，以及自动更新使用的 `nightly-mac.yml` / `nightly.yml`。

### 升级说明

- **从 0.4.2 升级**：通过自动更新送达，下载前和重启安装前都会询问；也可在应用菜单中点**检查更新…**。
- **从 0.4.0 或 0.4.1 升级**：这些版本没有更新功能，请手动覆盖安装一次。会话、设置和 MiMo Key 都会保留。
- **之前用过 PTC 或极简模式**：用它们建立的会话照常可以打开和继续；若曾把其中之一设为新任务默认，升级后会自动改回「标准模式」。
- 内核仍为官方 dsh Desktop 0.1.7-rc.2。

---

Mio gets out of the way: DeepSeek sign-in, the feedback controls and the preview notice are gone, the home screen carries Mio's own bilingual line, and thinking offers just on and off, as MiMo actually supports.

### Changes

- **New home-screen line** — the empty conversation shows 「于深处写下光」 with *Write Light into the Deep* beneath it; the badge beside it now reads "Built on DeepSeek Harness", stating plainly that Mio is built on the official dsh.
- **No DeepSeek account sign-in** — the Account settings page, the sidebar account menu and the account-billed model route are gone. MiMo and DeepSeek both connect by API key; the DeepSeek API-key route works as before.
- **No feedback controls** — Like / Dislike under replies, the feedback dialog and `/feedback` are gone.
- **No preview notice or DeepSeek onboarding** — a browser opening the same local Host no longer shows the "preview" notice or the "configure DeepSeek models" dialog.
- **Fewer agent presets** — new tasks offer *Standard* and *Creator* (where you build custom presets); *PTC* and *Minimal* no longer appear in Settings or the mode picker.
- **Thinking is on or off** — per Xiaomi's official docs, MiMo V2.6 thinking has exactly two states. The model menu drops the "Default" entry that only repeated High, leaving Off and High (on).

### Downloads and signing

- **macOS Apple Silicon:** `mac-arm64.dmg` or ZIP.
- **macOS Intel:** `mac-x64.dmg` or ZIP.
- **Windows x64:** `win-x64-unsigned.exe`. **This Windows installer is unsigned**; expect an unknown-publisher / SmartScreen prompt. Automatic updates verify downloads by SHA-512. macOS downloads are Developer ID signed and notarized.
- SHA-256 checksums, per-platform qualification evidence, and the `nightly-mac.yml` / `nightly.yml` update feed accompany the downloads.

### Upgrade notes

- **From 0.4.2**: arrives through automatic updates; Mio asks before downloading and before restarting to install. **Check for Updates…** in the application menu checks right away.
- **From 0.4.0 or 0.4.1**: those versions cannot update themselves; install over them once by hand. Sessions, settings and your MiMo key are kept.
- **If you used PTC or Minimal**: sessions created with them still open and continue; if one was your default for new tasks, it is switched back to *Standard* on upgrade.
- Still built on the official dsh Desktop 0.1.7-rc.2.
