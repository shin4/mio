# Mio 0.5.0-rc.1 — 未发布候选版

开发版已升级到 dsh 0.2.0-rc.2。安装包、真实 API 和跨平台资格尚未完成，生产仍为 0.4.5。

- 保留 MiMo 接入、图片、语音输入、朗读与媒体工具，沿用官方 Desktop 新版行为。
- V2.6 Flash、Pro、UltraSpeed 默认上下文为 1M（1,048,576 tokens）；旧配置继承的 256K 默认值自动修复，显式自定义上限保留。
- 新增产品命令 `mio`，与 GUI 使用同一个默认数据目录；自定义目录通过 `MIO_HOME` 配置。
- 默认关闭新增的产品 analytics；Session Log 为独立的上游设置。
- 旧 `transcriptView: normal` 按上游规则变为 `detailed`；新 profile 默认 `standard`。

**已有自动化任务的用户必须重新启用：**升级后打开“插件 → 官方 → 自动化任务”，启用
`@deepseek-ai/dsh-experimental-schedule-bundle`。已有任务保留在磁盘，重新启用前不会投递。
保留自定义 Schedule 配置，启用后确认任务列表及下次触发时间。

升级前退出 GUI/CLI 并备份完整 userData 和自定义 home。回退时保留新版数据副本，恢复
旧安装包与完整升级前备份；不要直接让旧版本读取新版写入后的数据。

验收状态见 [实施证据](../../docs/dsh-upgrade-0.2.0-rc.2-evidence.md)。
