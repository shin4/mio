## Mio v0.4.4

Mio 现在能看图，也能听录音、看视频：MiMo V2.6 直接理解你贴进来的图片，附上的音频和视频由 MiMo 听完、看完再告诉 Mio。

### 新功能

- **图片输入** — MiMo V2.6 Flash 和 Pro 现在接受图片。截图、设计稿、报错界面可以直接拖进或粘贴到输入框，模型会连同文字一起看。此前 Mio 没有声明这两个模型支持图片，输入框会拒绝图片。
- **音频与视频理解** — 附上录音或视频后，Mio 会调用新工具 `mimo_media_read`，让 MiMo（默认 `mimo-v2.6-flash`）听完或看完文件，再按需要给出转写、摘要或某个时刻发生了什么。支持 MP3、WAV、FLAC、M4A、OGG 音频和 MP4、MOV、AVI、WMV 视频，单个文件经 Base64 编码后不超过 50 MB。
- 两者都使用你已连接的 MiMo 账号和订阅套餐地域，无需额外的 Key。图片、音频和视频会发送到 MiMo API。

### 暂不支持

- **PDF** — MiMo 的接口目前不接受 PDF 或其他文档文件，Mio 会明确拒绝，不会假装读过。可以把 PDF 页面截图后作为图片发送。

### 下载与签名

- **macOS Apple Silicon：** `mac-arm64.dmg` 或 ZIP。
- **macOS Intel：** `mac-x64.dmg` 或 ZIP。
- **Windows x64：** `win-x64-unsigned.exe`。**Windows 安装包未签名**，可能出现未知发布者 / SmartScreen 提示；自动更新以 SHA-512 校验下载内容。macOS 安装包已 Developer ID 签名并公证。
- 附 SHA-256 校验和、各平台验证记录，以及自动更新使用的 `nightly-mac.yml` / `nightly.yml`。

### 升级说明

- **从 0.4.2 或 0.4.3 升级**：通过自动更新送达，下载前和重启安装前都会询问；也可在应用菜单中点**检查更新…**。
- **从 0.4.0 或 0.4.1 升级**：这些版本没有更新功能，请手动覆盖安装一次。会话、设置和 MiMo Key 都会保留。
- 内核仍为官方 dsh Desktop 0.1.7-rc.2。

---

Mio can now see images, and hear recordings and watch videos: MiMo V2.6 reads the pictures you paste in, and MiMo listens to or watches attached audio and video and reports back to Mio.

### New

- **Image input** — MiMo V2.6 Flash and Pro now accept images. Drag or paste screenshots, mockups and error screens into the composer and the model reads them with your text. Mio previously did not declare image support for these models, so the composer refused images.
- **Audio and video understanding** — attach a recording or a video and Mio calls the new `mimo_media_read` tool: MiMo (`mimo-v2.6-flash` by default) listens to or watches the file and returns what Mio asked for, such as a transcript, a summary or what happens at a given moment. MP3, WAV, FLAC, M4A and OGG audio and MP4, MOV, AVI and WMV video are supported, up to 50 MB per file once Base64-encoded.
- Both use the MiMo account and Token Plan region you already connected; there is no extra key. Images, audio and video are sent to the MiMo API.

### Not yet supported

- **PDF** — MiMo's API does not accept PDF or other document files today, so Mio refuses them plainly instead of pretending to have read them. Screenshot the pages and send them as images instead.

### Downloads and signing

- **macOS Apple Silicon:** `mac-arm64.dmg` or ZIP.
- **macOS Intel:** `mac-x64.dmg` or ZIP.
- **Windows x64:** `win-x64-unsigned.exe`. **This Windows installer is unsigned**; expect an unknown-publisher / SmartScreen prompt. Automatic updates verify downloads by SHA-512. macOS downloads are Developer ID signed and notarized.
- SHA-256 checksums, per-platform qualification evidence, and the `nightly-mac.yml` / `nightly.yml` update feed accompany the downloads.

### Upgrade notes

- **From 0.4.2 or 0.4.3**: arrives through automatic updates; Mio asks before downloading and before restarting to install. **Check for Updates…** in the application menu checks right away.
- **From 0.4.0 or 0.4.1**: those versions cannot update themselves; install over them once by hand. Sessions, settings and your MiMo key are kept.
- Still built on the official dsh Desktop 0.1.7-rc.2.
