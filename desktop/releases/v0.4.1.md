## Mio v0.4.1

Mio 现在会听，也会说：用 MiMo ASR 说出需求，用 MiMo TTS 收听回复。

### 新功能

- **语音输入（MiMo ASR）** — 点输入框里的麦克风说出需求（最长 60 秒），`mimo-v2.5-asr` 会把它转成草稿，确认后再发送。识别语言默认自动判断，也可在**插件 → 语音输入**中固定为中文。
- **朗读回复（MiMo TTS）** — 每条完成的回复在复制按钮旁多了一个朗读按钮。`mimo-v2.5-tts` 朗读正文，跳过代码块，同一时间只播放一条，再点一次即停止。长回复从开头按整句朗读，最多约 4,000 字。
- **朗读音色** — **设置 → 通用设置 → 朗读音色**提供 9 种预置音色（默认、冰糖、茉莉、苏打、白桦、Mia、Chloe、Milo、Dean），可试听，选择立即生效。
- 两者都使用你已连接的 MiMo 账号和订阅套餐地域，无需额外的 Key，也不下载本地模型。录音与回复文本会发送到 MiMo API。

### 下载与签名

- **macOS Apple Silicon：** `mac-arm64.dmg` 或 ZIP。
- **macOS Intel：** `mac-x64.dmg` 或 ZIP。
- **Windows x64：** `win-x64-unsigned.exe`。**Windows 安装包未签名**，可能出现未知发布者 / SmartScreen 提示；macOS 安装包已 Developer ID 签名并公证。
- 附 SHA-256 校验和与各平台的验证记录。

### 升级说明

- 需手动安装，仍未启用自动更新。
- **从 0.4.0 升级：**直接覆盖安装，会话、设置和 MiMo Key 都会保留。朗读立即可用；由 0.4.0 创建的配置默认未开启语音输入，请在**插件 → 语音输入**中开启一次。
- **从 0.3.x 升级：**0.4 使用全新的数据目录，不迁移旧的会话、设置或 Key，请在欢迎页重新连接 MiMo 账号。
- 内核仍为官方 dsh Desktop 0.1.7-rc.2。Linux 后续单独提供。

Mio now listens and speaks: talk to it with MiMo ASR, and hear replies with MiMo TTS.

### New

- **Voice input (MiMo ASR)** — click the mic in the composer and speak (up to 60 seconds). `mimo-v2.5-asr` turns it into a draft that is sent only when you send it. The language is detected automatically, or can be pinned to Chinese under **Plugins → Voice input**.
- **Read aloud (MiMo TTS)** — every finished reply gets a speaker button next to Copy. `mimo-v2.5-tts` reads the prose, skips code blocks, and plays one reply at a time; click again to stop. Long answers are read from the start, in whole sentences up to about 4,000 characters.
- **Read-aloud voice** — **Settings → General → Read-aloud voice** offers nine preset voices (default, 冰糖, 茉莉, 苏打, 白桦, Mia, Chloe, Milo, Dean) with a preview. The choice applies immediately.
- Both use the MiMo account and Token Plan region you already connected. There is no extra key and no local model download. Recordings and reply text are sent to the MiMo API.

### Downloads and signing

- **macOS Apple Silicon:** `mac-arm64.dmg` or ZIP.
- **macOS Intel:** `mac-x64.dmg` or ZIP.
- **Windows x64:** `win-x64-unsigned.exe`. **This Windows installer is unsigned**; expect an unknown-publisher / SmartScreen prompt. macOS downloads are Developer ID signed and notarized.
- SHA-256 checksums and per-platform qualification evidence accompany the downloads.

### Upgrade notes

- Install manually; automatic updates are still disabled.
- **From 0.4.0:** install over it. Sessions, settings and your MiMo key are kept. Read aloud works right away. Voice input starts switched off in profiles created by 0.4.0; turn on **Plugins → Voice input** once.
- **From 0.3.x:** 0.4 uses a fresh data directory and does not migrate earlier sessions, settings or keys. Reconnect your MiMo account on the welcome screen.
- Still built on the official dsh Desktop 0.1.7-rc.2. Linux will follow separately.
